<h2 id="北交所新旧代码对照表">北交所新旧代码对照表</h2>
<hr/>
<p>接口：bse_mapping<br/>描述：获取北交所股票代码变更后新旧代码映射表数据<br/>限量：单次最大1000条（本接口总数据量300以内）<br/>积分：120积分即可调取</p>
<br/>
<br/>

<th>类型</th>

<th>描述</th>
</tr>
</thead>
<tbody><tr>
<td>o_code</td>
<td>str</td>
<td>N</td>
<td>旧代码</td>
</tr>
<tr>
<td>n_code</td>
<td>str</td>
<td>N</td>
<td>新代码</td>
</tr>
</tbody></table>

<table>

<p><strong>接口示例</strong></p>
<pre><code class="language-python">
#获取方大新材新旧代码对照数据
df = pro.bse_mapping(o_code='838163.BJ')


#获取全部变更的股票代码对照表
df = pro.bse_mapping()

</code></pre>
