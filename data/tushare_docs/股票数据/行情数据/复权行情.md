<h2 id="a股复权行情">A股复权行情</h2>
<hr/>
<p><strong>接口名称</strong> ：pro_bar<br/><strong>接口说明</strong> ：复权行情通过<a href="https://tushare.pro/document/2?doc_id=109">通用行情接口</a>实现，利用Tushare Pro提供的<a href="https://tushare.pro/document/2?doc_id=28">复权因子</a>进行动态计算，因此http方式无法调取。若需要静态复权行情（支持http），请访问<a href="https://tushare.pro/document/2?doc_id=296">股票技术因子接口</a>。<br/><strong>Python SDK版本要求</strong>： &gt;= 1.2.26</p>
<br/>
<br/>
<p><strong>复权说明</strong></p>
<table>
<thead>
<tr>
<th>类型</th>
<th>算法</th>
<th>参数标识</th>
</tr>
</thead>
<tbody><tr>
<td>不复权</td>
<td>无</td>
<td>空或None</td>
</tr>
<tr>
<td>前复权</td>
<td>当日收盘价 × 当日复权因子 / 最新复权因子</td>
<td>qfq</td>
</tr>
<tr>
<td>后复权</td>
<td>当日收盘价 × 当日复权因子</td>
<td>hfq</td>
</tr>
</tbody></table>
<br/>
<br/>
注：目前只支持A股的日线复权。在Tushare数据接口里，不管是旧版的一些接口还是Pro版的行情接口，都是以用户设定的end_date开始往前复权，跟所有行情软件或者财经网站上看到的前复权可能存在差异，因为行情软件都是以最近一个交易日开始往前复权的。比如今天是2018年10月26日，您想查2018年1月5日～2018年9月28日的前复权数据，Tushare是先查找9月28日的复权因子，从28日开始复权，而行情软件是从10月26日这天开始复权的。同时，Tushare的复权采用“分红再投”模式计算。

<p><strong>接口用例</strong></p>
<p>日线复权</p>
<pre><code class="language-python">
#取000001的前复权行情
df = ts.pro_bar(ts_code='000001.SZ', adj='qfq', start_date='20180101', end_date='20181011')

#取000001的后复权行情
df = ts.pro_bar(ts_code='000001.SZ', adj='hfq', start_date='20180101', end_date='20181011')
</code></pre>
<br/>
<p>周线复权</p>
<pre><code class="language-python">
