<h2 id="a股日线行情">A股日线行情</h2>
<hr/>
<p>接口：daily，可以通过<a href="https://tushare.pro/webclient/"><strong>数据工具</strong></a>调试和查看数据<br/>数据说明：交易日每天15点～16点之间入库。本接口是未复权行情，停牌期间不提供数据<br/>调取说明：基础积分每分钟内可调取500次，每次6000条数据，一次请求相当于提取一个股票23年历史<br/>描述：获取股票行情数据，或通过<a href="https://tushare.pro/document/2?doc_id=109"><strong>通用行情接口</strong></a>获取数据，包含了前后复权数据</p>

<td>交易日期（YYYYMMDD）</td>

<p><strong>接口示例</strong></p>
<pre><code class="language-python">
pro = ts.pro_api()

df = pro.daily(ts_code='000001.SZ', start_date='20180701', end_date='20180718')

#多个股票
df = pro.daily(ts_code='000001.SZ,600000.SH', start_date='20180701', end_date='20180718')
</code></pre>
<p>或者</p>
<pre><code class="language-python">
df = pro.query('daily', ts_code='000001.SZ', start_date='20180701', end_date='20180718')
</code></pre>
<p>也可以通过日期取历史某一天的全部历史</p>
<pre><code class="language-python">
df = pro.daily(trade_date='20180810')
</code></pre>
