<h2 id="基金规模数据">基金规模数据</h2>
<hr/>
<p>接口：fund_share，可以通过<a href="https://tushare.pro/webclient/"><strong>数据工具</strong></a>调试和查看数据。<br/>描述：获取基金规模数据，包含上海和深圳ETF基金<br/>限量：单次最大提取2000行数据<br/>积分：用户需要至少2000积分可以调取，5000积分以上频次较高，具体请参阅<a href="https://tushare.pro/document/1?doc_id=13">积分获取办法</a> </p>
<br/>
<br/>

<p><strong>代码示例</strong></p>
<pre><code class="language-python">#初始接口
pro = ts.pro_api()

#单只基金
df = pro.fund_share(ts_code='150018.SZ')

#多只基金
df = pro.fund_share(ts_code='150018.SZ,150008.SZ')
</code></pre>
